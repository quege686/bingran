合作流程

1
准备货品

2
发布商品链接

3
选款 → 寄样

4
买手核实与核价
买手二次核实图片和二次拿实物核价 → 审核通过（不通过有重新报价机会）
5
下备货申请单
自己下备货申请单 → 发大货到仓库（JIT模式加虚拟库存，售出后发仓库）

入库上架 → 结算

常见问题

Q：为什么同样的款别人能过我不过？

A：站内没有跑成爆旺的款，仅限两个连接，超过两个就会提示站内同款过多。要是有特殊情况，可以手机实拍，平铺地下上款，这样就会重新选中。

Q：全托与半托上传区别？

A：全托是平台代运营，款发送国内仓库，卖出一件结算一件。半托需要自行配送至海外。

Q：全托不同店铺区别？

A：全托店铺按照买手，目前有常规店铺、OBM 1/2店铺、印花店铺、常规组印花店铺、VMI印花店铺。每个店铺都对应不同的买手组。其中常规店铺/OBM店铺都有一定免审规则。印花店铺、常规组印花店铺需要走底版寄样。VMI印花店铺为中间态，归属常规买手下，根据以后上款风貌转为对应的印花/常规店铺。

Q：常规店铺分类？

A：常规店铺又分为常规无标签店铺、品牌店铺、竞对同源店铺。按照对应情况有一定的加权。

商品上新

尺码重要说明：我们做的是北美市场、欧洲、加拿大、非洲等，所有尺寸都需要是美版标准！美版尺码对应的尺寸数字，不同尺码间跳码标准，切记看清楚。尺码都是基础码的尺寸，例如卫衣基础码M码的尺寸要求，裤子是32码的各个版型的尺寸。所有商品都需要按美码标准去发布。如果是国内版型货，要修改好样衣和大货尺码标和商品尺码表，对照美版尺码标准。忽略一切中国码的字眼，一切尺寸参照美版的尺码表去填写你上架的商品。
尺寸允差标准：主要部位 / 次要部位 / 重量允差
QC现场检核重点：底线品质 / 服装包装 / 洗水唛 / 童装安全 / 鞋靴包配

男装资质要求

影响加站和商品入库。服装商品都需要办理欧代。服务市场已有8家欧代服务商，200~400元/年，店铺维度办理。
