对接买手合作流程
完整流程
按图片要求、尺码要求、价格需求的货 → 后台发布商品链接 → 选款 → 寄出样（免审不用寄样，快递自费）→ 助理收样 → 审版 → 买手二次核实图片和二次拿实物核价 → 审核通过（不通过有重新报价机会）→ 自己下备货申请单 → 发大货到仓库（JIT模式加虚拟库存，售出后发仓库）→ 入库 → 上架售卖 → 卖出后11-15日人民币结算到店铺后台 → 提现
重要提醒
选完符合价位的款，大家开始发布商品。切记要发布在我们给的类目中，否则不算我们组业绩！
发布货品特别注意 ‼
千万注意
1. 类目归属和属性一定要填写正确，都用中文发布，参考国内电商命名方式：如面料（涤纶）、风格、版型、属性、品类都要写进来。
2. 标题必须和货品实际对照得上，否则审版不过链接作废。例如你是否宽松版型，不是国内尺码算宽松即可，而是要在美版的尺寸基础上是否宽松才算宽松。
3. 如果偏薄一定要备注偏薄。
4. 是纯棉再写纯棉，是棉服不要写羽绒服，罚款自负。
5. 如果不是底版，不要勾选底版。
常见问题 Q&A
Q：为什么同样的款别人能过我不过？
站内没有跑成爆旺的款，仅限两个连接，超过两个就会提示站内同款过多。要是有特殊情况，可以手机实拍，平铺地下上款，这样就会重新选中。
Q：全托与半托上传区别？
全托是平台代运营，款发送国内仓库，卖出一件结算一件。半托需要自行配送至海外。
Q：全托不同店铺区别？
全托店铺按照买手，目前有常规店铺、OBM 1/2店铺、印花店铺、常规组印花店铺、VMI印花店铺。每个店铺都对应不同的买手组。其中常规店铺/OBM店铺都有一定免审规则。印花店铺、常规组印花店铺需要走底版寄样。VMI印花店铺为中间态，归属常规买手下，根据以后上款风貌转为对应的印花/常规店铺。
Q：常规店铺分类？
常规店铺又分为常规无标签店铺、品牌店铺、竞对同源店铺。按照对应情况有一定的加权。

四、商品上新
▼
尺码重要说明
我们做的是北美市场、欧洲、加拿大、非洲等，所有尺寸都需要是美版标准！
美版尺码对应的尺寸数字，不同尺码间跳码标准，切记看清楚，否则一切都是徒劳。
尺码说明（必看）
• 先打开文件查看各品类尺寸标准。尺码都是基础码的尺寸，例如卫衣基础码M码的尺寸要求，裤子是32码的各个版型的尺寸。
• 所有商品都需要按美码标准去发布。你的M码就是美版的M码尺寸要求。
• 如果是国内版型货，要修改好样衣和大货尺码标和商品尺码表，对照美版尺码标准。
• 拿卫衣举例：你的常规肩的M码胸围是108，而不是中国尺寸。忽略一切中国码的字眼。
• 一切尺寸参照美版的尺码表去填写你上架的商品链接里面的尺码表内的尺寸数字。

核价规则

核价模板：
SKC：XXX 最低价XX，原因：面料费用XX元 + 损耗费XX元 + 辅料XX+XX+XX XX元 + 工价XX元 + XXX费+XX费 X元 = 成本XX元
利润：30%

审价流程：第一遍申请人审，24h刷价。人审不过 → 继续提报 → 人工审核。
二次人工审核给不到合适价位 → 放弃，或换一组图（站内比价主要看主图）重新上连接。
免审规则
免审说明
目前基本按照我们给出的类目上，都能免审掉，如果不免审可以DD买手看，买手乐意解决。
1. 上非免审类目，已审版套版
已经寄样过的SPU，上同款，给已审SPU。
2. 跨境商家免审
在SHEIN、TikTok、速卖通、亚马逊、虾皮、Lazada、美客多等跨境平台有开店，可截图后台店铺评分+一个在售链接，发送给买手判断是否符合要求（如OBM需≥4.8分，ODM、OEM、FOB等无评分要求），即可申请Temu店铺全店免审。
3. 品牌免审
拼多多主站黑标品牌/天猫品牌+评分三红/唯品会品牌/得物店铺（男装单月GMV过600W）/淘宝金冠+评分三红（男装单月GMV过600W）/拼多多主站连续6个月月GMV过100W且DSR排名前65%，可申请Temu店铺全店免审，并可在前端页面打上品牌标，获得更多搜推流量加成。

九、男装资质要求
▼
重要提醒
商家必做以下资质，否则对加站和提现、商品入库都会有影响！
资质清单
1. 欧盟授权代理（欧代）
影响加站和商品入库。根据欧盟GPSR法规要求，服装商品都需要办理欧代。目前服务市场已有8家欧代服务商入驻，商家可前往后台下单办理（VAT banner下面），200~400元，有效期一年，店铺维度办理。
2. 德国EPR
影响提现和欧盟加站。德国包装法注册无费用，15分钟内注册完成。注册号上传路径：账户管理→主体管理→主体详情→生产者延伸责任。
3. 反洗钱合规填写
影响提现和加站。根据美国INFORM法案要求，需商家填写反洗钱法案信息。登录合规登记页面填写，避免商品被下站和限制加站。
4. 法国纸张申报
影响提现。店铺后台完成申报后隔天晚11点后解冻资金。
5. 奥地利EPR
影响奥地利站点销售。针对销售至奥地利的商品，有关责任人需缴纳环保回收费。奥地利将对包装（含一次性塑料产品）、电子电器、电池三个环保品类进行管控。
6. GCC
影响特定品类。可豁免条件：①隶属于成分（6种：腈纶、变性腈纶、尼龙、烯烃、聚酯、羊毛）之内，且含量之和为100%；②光面且克重大于88.18g/平方，26股丝。满足任意一个条件即可豁免。
7. 制造商地址
影响美国站点销售。根据美国站点海关需要，请商家及时维护商品制造商相关字段：制造商名称、地址、国家、城市、邮编。注意不要把实物标签上的欧代地址填写成制造商地址。
